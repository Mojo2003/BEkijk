# BEkijk

**Your Belgian TV guide, all in one place.**

BEkijk is a modern TV guide application focused on Belgian television channels. Its goal is to make discovering what's on TV simple, intuitive and enjoyable.

## Features

- Browse Belgian TV channels and their programming.
- Explore what's currently on TV.
- Discover upcoming programmes.
- Clean, modern and responsive interface.
- Blue-themed visual identity.

## Tech Stack

- React
- TypeScript
- Vite
- Node.js

## Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### Installation

Clone the repository:

```bash
git clone https://github.com/Mojo2003/BEkijk.git
```

Navigate to the project directory:

```bash
cd BEkijk
```

Install dependencies:

```bash
npm install
```

### Environment Variables

If the project requires environment variables, create a `.env` file based on `.env.example` and configure the required values.

Never commit your actual `.env` file or API keys.

### Run Locally

Start the development server:

```bash
npm run dev
```

Follow the URL displayed in your terminal to open BEkijk in your browser.
